01 — About

关于我

一名在校园里做产品的全栈开发者：写界面、写接口，也写知识图谱与 Agent。

我是苑泽宇，四川大学软件工程在读，一名全栈开发者。日常在 React / Vue 的组件树与 Node.js / Python 的服务端之间穿梭，也把不少时间花在 AI Agent、知识图谱与 LLM 集成上。

近一年我把重心放在心理健康方向的数字化产品：从量表测评、危机预警看板到知识图谱，把「技术」落到具体的人身上——一套 20 题的测评能生成四级预警，一张知识图谱能把零散的心理健康知识组织成可探索的网络。此外也接触过金蝶苍穹 Agent Studio 等企业级平台，做过覆盖 11 张数据表的 HR 管理系统。
